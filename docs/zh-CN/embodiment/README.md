# 本体扩展 / 灵巧操作

[首页](../../../README.zh-CN.md) | [英文](../../en/embodiment/README.md)

本体扩展决定具身智能是否能从单机械臂走向人形、双臂、灵巧手和触觉接触任务。表中论文体现了动作空间、传感方式和控制目标随本体变化而复杂化。

子方向：人形机器人、双臂操作、灵巧手、触觉与接触丰富操作。

> 本节表格采用“固定总宽度 + 明确列宽”的组合方式：会议、验证等短字段保持单行，问题、瓶颈等长字段在指定宽度内换行；窄屏下仍可横向滑动。
