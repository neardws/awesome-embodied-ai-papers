# WAM / 世界模型

[首页](../../../README.zh-CN.md) | [英文](../../en/wam/README.md)

WAM 将未来世界状态预测和动作生成合在一起，适合放在智能体规划和低层控制之间。它的价值不是替代所有控制器，而是提供可想象、可验证、可恢复的中间层。

子方向：级联世界动作模型、联合世界动作模型、视频/潜在世界模型、面向 VLA 的世界模型。

共 70 篇。
